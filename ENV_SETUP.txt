VPS par ye environment variables set karein (sab aapke apne):

BOT_TOKEN   = BotFather se apne bot ka token
API_ID      = my.telegram.org se
API_HASH    = my.telegram.org se
DB_URI      = apna MongoDB connection string
DB_NAME     = SaveRestricted2   (ya jo naam chahein)
ADMINS      = aapki numeric Telegram ID  (agar kai hon to comma se: 111,222)
LOG_CHANNEL = apne log channel ki ID (-100...)
